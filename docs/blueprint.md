# **App Name**: E-Vision Hub

## Core Features:

- User Authentication: Secure signup/login with a soft, visually appealing pastel interface. Uses Firebase Auth
- Role-Based Dashboards: Custom dashboards for Faculty, President, VP, Core & General members with appropriate data overviews and access levels. Data will be able to filter using the specified categories.
- Daily Progress Input: Pastel UI for entering daily progress, uploading images, and viewing progress history with filtering.
- AI Progress Feedback: Provide feedback to users about their daily progress. Uses AI as a tool to identify potential areas for improvement, personalized tips, and motivational messages, and show on progress card
- Event & Hackathon Module: Display events and hackathons using pastel-themed banner cards, countdowns, and guest profile bubbles with tag filters.
- Team Management: Display team cards with member avatars, soft background gradients, role tags, and progress graphs, enable the team's ability to send out team join request cards.
- AI Learning Resources: Recommend learning resources and personalized event suggestions. Uses AI to sift through a resource bank to give user resources fitting for their profile

## Style Guidelines:

- Primary color: Lavender (#E6E6FA) to set a soft and calming tone.
- Background color: Off-white (#F8F8FF), desaturated lavender hue, to create clean surfaces with enough contrast in a light scheme.
- Accent color: Mint green (#E0FFD4), a cooler color on the spectrum, for subtle interactive highlights.
- Font pairing: 'Poppins' for headlines (geometric sans-serif), and 'PT Sans' for body text (humanist sans-serif).
- Use elegant line icons with a pastel color palette to match the soft design.
- Employ a light and airy layout with beautiful spacing and padding, focusing on readability.
- Incorporate subtle animations using Framer Motion to create smooth transitions and interactions.
